# How to use this package
1. clone this repo to your catkin source folder
   ```
   cd {xxx}/catkin_{xxx}/src
   git clone https://gitee.com/xjtu_vcciv/kf-msgs.git
   ```

2. change to the correct stable version
   ```
   git checkout v{x}.{x}.{x}
   ```

3. compile this package using catkin_make
   ```
   catkin_make -DCMAKE_BUILD_TYPE=release
   ```
